# 03 분석 및 모델링 (팀원 원본 수령 대기)

이 단계의 실제 분석·모델링 코드는 아직 받지 않았습니다. 임의로 재현 결과를 만들지 않습니다.

팀원에게 받아 추가할 파일:
- EDA 코드 및 그래프 생성 코드
- 실제 모델에 사용한 최종 데이터 버전(발표 기준 33,964행; 예: flight_preprocessed_final_v3.csv)
- Random Forest / XGBoost / LightGBM 비교 코드
- 시간순 데이터 분할·GridSearchCV·클래스 가중치·임계값 최적화 코드
- 모델 저장/불러오기 코드, best_flight_delay_model.pkl (로컬 공유)
- 실제 패키지 버전과 모델 입력 컬럼 및 인코딩 방식, 최종 threshold

데이터와 pkl은 로컬 공유하고 코드만 GitHub에 추가합니다. pickle 파일은 직렬화된 파일이며 암호화된 파일이 아닙니다. 신뢰할 수 있는 팀원 파일만 로드하세요.

발표 수치: 지연 Recall 0.44, F1 0.35, Accuracy 0.76. 해당 수치는 발표 자료에 기록된 결과이며 여기의 시연용 전처리 데이터로 재현되었다는 뜻은 아닙니다.
